A container with nothing declared

Capped at --measure-content (48rem) and centred, because those are the declared defaults. Most body copy wants exactly this.

--measure-prose is 65ch, so this column tracks the reader's font rather than the page's grid: raise the base font size and the measure grows with it, keeping the line length at the same number of characters.

--measure-wide (72rem) is the page-shell measure: wide enough for a documentation page or a dashboard, narrow enough that it still reads as a column on a large display.

full is the deliberate opt-out. The column keeps its gutter but imposes no maximum, which is what a bleed section wants.

A gutter is inline padding only — the space beside the column, never above it. Vertical rhythm belongs to the stack inside.

Below the lg tier this is a 32rem column; from 64rem up it is a 72rem one. Mobile-first, on the breakpoint canon.
